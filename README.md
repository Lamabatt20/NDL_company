# NDL Project

NDL is a modern digital platform that provides engineering and design services through a clean and interactive web interface.

The platform showcases multiple services such as mechanical design, product design, and manufacturing solutions, allowing users to explore services easily and understand the company’s capabilities.

---

## Features

- Modern and responsive UI design  

- Multiple service sections (Mechanical, Aluminum, Steel, Wood, Product Design, etc.)  

- Interactive navigation between services  

- Clean and user-friendly layout  

- Scalable and modular component structure  

- Optimized performance for web experience  

---
